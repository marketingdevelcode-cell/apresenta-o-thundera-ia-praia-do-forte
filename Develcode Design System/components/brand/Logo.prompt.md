Renders an official Develcode logo lockup from the shipped PNGs — use it anywhere a brand mark is needed.

```jsx
<Logo variant="horizontal-white" height={36} assetsBase="../../assets/logos" />
```

Variants: `horizontal-black` (light backgrounds), `horizontal-white` (blue/dark backgrounds), `mark-blue` `mark-white` (square X mark for avatars, favicons, badges) and `mark-tile` (white mark on a rounded blue tile — app icon, favicon, social avatar). `lockup-2026` is the cover lockup with the year set beneath the wordmark — use it on title slides and never add a separate year label next to it. Clear space = height of the X mark on all sides. Never recolour, outline or stretch the lockup.
